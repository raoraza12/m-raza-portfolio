---

## ✨ Key Features

- **Kinetic Typography & Fluid Motion**: Dynamic variable font stretching, GSAP scroll triggers, and Lenis smooth scrolling.
- **AI Portfolio Representative**: Interactive AI chat modal equipped to answer visitor questions regarding Raza's experience, stack, and showcased projects.
- **Local Client Isolation**: Chat histories are saved strictly to the visitor's local device storage with zero cross-user leakage.
- **Curated Projects Showcase**:
  - **[Drake Wears](https://drakewears.com)**: Premium apparel and kinetic e-commerce experience.
  - **[Earthy Electronics](https://earthyelectronics.com)**: Next-gen tech & electronics digital marketplace.
  - **HealthMate**: Comprehensive health telemetry and consultation platform.
  - **Nexus AI Book**: AI-native interactive narrative generation engine.
  - **Salt & Pepper**: Culinary branding and real-time ordering digital experience.
- **100% Responsive Design**: Carefully optimized for ultra-smooth touch navigation across all mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite
- **Styling:** Vanilla CSS, HSL modern dark-mode palettes, Glassmorphism
- **Animations & 3D:** GSAP (ScrollTrigger), Lenis Smooth Scroll, Three.js
- **Deployment:** Vercel (Auto-deploy via GitHub)
